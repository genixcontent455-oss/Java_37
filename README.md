# Screenshots

This folder is intentionally supplied without fabricated screenshots.

Add genuine screenshots captured from your own run of Project 37. Suggested files:

1. `01-main-menu.png` — the console menu after starting `Main`.
2. `02-seating-plan.png` — menu option 9 output showing the seating matrix.
3. `03-ticket-validation.png` — successful and rejected hall-ticket validation cases.
4. `04-attendance-report.png` — the finalised session attendance report.

## How to capture

1. Compile and run the application using the commands in the root `README.md`.
2. Select menu option `9` for the scripted demonstration, or use the individual menu options.
3. Capture the terminal window using your operating system's screenshot tool.
4. Save the PNG files in this directory using the names above.
5. Reference the images from the root README if you want them displayed on the repository home page, for example:

   ```markdown
   ![Seating plan](docs/screenshots/02-seating-plan.png)
   ```

Do not place real student credentials, private candidate information, or real hall-ticket secrets in screenshots. The built-in demonstration uses synthetic data.
